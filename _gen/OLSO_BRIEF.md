# 중학 사회·역사 문제은행 채우기 — 과정 하나 담당 지침 (2026-09-28)

학습지앱(학원 학생용, 비공개 앱)의 중학 사회·역사 8과정은 지금 **단원 트리도 문항도 없다.**
너는 과정 **하나**(`<C>` = 예: m-soc1-1)를 맡아 아래 4가지를 만든다.
작업 폴더: `_gen/<C>/` (저장소 루트 = 이 파일이 있는 `_gen/` 의 상위)

## 재료 (읽기 전용, 글자로 뽑아 둠) — `../olso/txt/` (저장소 기준 `../olso/txt/`)
| 파일 | 내용 |
|---|---|
| `<C>_개념.txt` | (사회만) 개념 학습 정리책 교사용 — 목차·개념 설명·개념 확인·대표 문제·서술형 (정답 표시 포함) |
| `<C>_시험.txt` | (사회만) 시험 대비 문제책 교사용 — 실제 시험형 문항 + 정답·해설 |
| `<C>_교사용.txt` | (역사만) 본책 교사용 — 개념 + 문항 + 정답 |

각 파일은 `=== PDF pN ===` 로 쪽이 나뉜다. 필요한 부분만 grep/sed 로 골라 읽어라(통째로 읽지 마라).

## 만들 것

### ① `_gen/<C>/_tree.json` — 단원·유형 트리
`[대단원, [[중단원, [[소단원, [유형, 유형, …]], …]], …]]` (JSON 중첩 배열, 문자열만).
- 대단원·중단원 = **교재 목차 그대로**(번호 떼고 이름만). 소단원 = 그 중단원 안의 개념 덩어리(보통 2~3개).
- 유형 = 시험에서 **실제로 묻는 방식** 단위, 소단원당 2~4개. 예: 「기후 지역과 의식주 연결」 「위도·경도로 위치 판별」 「왕과 업적 짝짓기」 「사건 순서 배열」.
- 이름은 짧게(25자 이내). 유형 id 는 앱이 `<C>-u{대}m{중}s{소}t{유형}` 로 **순서대로** 자동 부여한다.

### ② 문항 — `_gen/<C>/p-u<대단원번호>.json` (대단원 하나에 파일 하나, 배열)
유형마다 **6문항**: diff 1, 2, 3, 3, 4, 5 (1=개념 확인 수준 … 5=자료 2개 이상 종합·함정 선지).
```json
{"id":"seed-<C>-u0m0s0t0-01","typeId":"<C>-u0m0s0t0","twinGroup":"tw-<C>-u0m0s0t0","kind":"객관식","diff":3,
 "body":"발문\n\n(자료 — 가상 대화·연표·표·기사 요약·조건 목록 등 글로 된 것)","choices":["…","…","…","…","…"],
 "answer":"③","solution":"1. …\n2. …\n3. 따라서 답은 ③이다.","source":"씨앗제조기 · 올쏘 유사유형"}
```
- **객관식이 기본**(보기 정확히 5개, 정답 ①~⑤). 정답 번호는 ①~⑤에 고루 흩어라.
- 주관식은 두 가지만: (a) **단답** — 답이 용어 하나(8자 이내), 발문에 「○○을 쓰시오」, `"kind":"주관식"`;
  (b) **서술형** — `"kind":"주관식","selfGrade":true`, answer 에 모범 답안(채점 기준 포함 가능). 과정 전체 문항의 15% 이내.
- 묻는 방식을 섞어라: 옳은 것/옳지 않은 것 · 합답형(ㄱㄴㄷㄹ 보기) · 가상 학생 대화(갑·을·병·정) · 연표·사건 순서 · 인물/왕–업적 짝 · 표 해석 · 사례→개념 · 빈칸 (가)(나).
  같은 유형 안에서 **같은 틀 반복 금지.**
- 🔴 **교재 문항을 옮겨 적지 마라.** 교재는 «시험에 무엇이 나오는지·사실이 무엇인지» 확인용이다.
  발문·자료·선지를 **새로 써라.** 교재 문장을 10어절 이상 그대로 이어 쓰지 마라. 사례·지명·수치를 바꿔라(사실인 것으로).
- 🔴 **그림·지도·사진·그래프를 봐야 풀리는 문항 금지**(앱은 글만 보여 준다). 「다음 지도의 A」「사진은」「그래프를 보고」 쓰지 마라.
  지리 위치는 말로 서술한다(「적도 부근, 남아메리카 아마존강 유역」). 기후 그래프는 수치를 표로 준다.
- 🔴 **사실이 틀리면 안 된다.** 교재 개념·해설에 있는 사실만 쓴다. 확실하지 않은 연도·수치·지명은 쓰지 마라.
  오답 선지도 «명백히 틀린» 것이어야 한다(정답이 두 개가 되는 선지 금지). 22개정 교재 서술을 기준으로 한다.
- 풀이는 번호 단계. 오답 선지가 왜 틀렸는지 한두 개는 짚어라.
- id 는 `seed-<typeId 뒷부분 포함>-NN` 처럼 과정 안에서 유일하게.

### ③ `_gen/<C>/_concepts.json` — 소단원마다 개념카드 1장 (승강제 0층 «개념 빈칸» 재료)
```json
{"id":"c-<C>-u0m0s0","subId":"<C>-u0m0s0","title":"<소단원 이름>","lines":["용어: 설명.", …]}
```
- lines 4~7줄. **「용어: 설명」 줄 최소 1줄**(용어 = 한글 2~11자, 숫자 없음; `성질:` 같은 일반 낱말 금지).
- **`$…$` 안에 괄호 밖 등호가 있는 줄 최소 1줄** — 사회·역사는 이렇게 쓴다:
  `$(\\text{고려의 건국}) = \\text{918년 왕건}$` · `$(\\text{열대 기후의 기준}) = \\text{최한월 평균 기온 18℃ 이상}$`
  (JSON 이므로 역슬래시 두 번. 우변은 두 글자 이상.)
- `예:` `참고:` `주의:` 로 줄을 시작하지 마라. 사실만.

### ④ `_gen/<C>/_wbmap.json` — 교재 채점 문항 → 새 유형 연결
`_gen/<C>/_wbitems.json` 에 올쏘 본책(사회=개념 학습 정리책, 역사=본책) 채점 문항 목록이 있다: `[문항id, 쪽, 정답]`.
(문항id: `개념NN`=개념 확인, `대표NN`=대표 문제, `서술NN`/그 밖=주관식·서술형. 쪽은 **교재 인쇄 쪽**.)
각 문항이 어느 소단원·유형을 묻는지 교재·해설을 보고 정해 `{"문항id": "<C>-u?m?s?t?"}` 로 **전부** 채워라.
쪽이 같은 문항은 대개 같은 소단원이다. 확신이 없으면 그 쪽이 속한 소단원의 가장 가까운 유형.

## 검사 — 통과할 때까지 고친다
```bash

```
olso_check 가 `✓ 통과` 를 내야 끝이다(형식·유형 id·보기·정답 분포·그림 의존 문구·wbmap 전수).
