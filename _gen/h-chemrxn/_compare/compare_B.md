# h-chemrxn 갈래 B — 시중 문제집(하이탑 화학 반응의 세계, 22개정 동아출판) 1:1 비교

범위: Ⅱ. 산화·환원 반응(교재 01 산화·환원 반응 / 02 화학 전지 / 03 표준 환원 전위 / 04 전기 분해 / 05 우리 주변의 산화·환원 반응) · Ⅲ. 탄소 화합물과 반응(01 탄소 화합물 / 02 탄소 화합물의 반응 / 03 중합 반응과 고분자 / 04 탄소 화합물의 유용성)
교재 구성(중단원마다): 기본 문제 8~12 · 실력 향상 문제 8 · 도전 문제 2 · 탐구 확인·집중 분석 유제 1~3 · 대단원 종합 16 + 서술형(Ⅱ 5, Ⅲ 4) · 창의 융합 논술(제시문).
문항 수는 정답과 해설의 문항별 해설과 교재 발문을 훑어 유형별로 나눈 대략값이다(한 문항이 두 유형에 걸치면 주된 쪽에 셈).

교재 범위 메모
- 전기 분해 양적 관계는 교재에서 «전자의 양(mol)·원자량»으로만 다룬다(패러데이 상수·전류×시간 계산 없음). 우리 유형 u1m2s0t2(전기량과 석출량)는 앱에 있는 유형이라 유지하되 상수와 식(F = 96500 C/mol, 전하량 = 전류 × 시간)을 문제에 주었다.
- 탄화수소 명명(IUPAC)·알케인 일반식은 교재 본문에 없다(메테인~뷰테인, 에텐, 에타인 이름만). 이성질체는 심화 상자(탄소 골격·위치·작용기·기하·광학)로만 나온다 → 우리 u2m0s0t1·t2 보강은 규칙을 문제에 제시하는 방식으로 만들었다.
- 치환 반응은 교재에서 거의 다루지 않는다(탄화수소 유도체 정의, 수크랄로스 설명뿐). 첨가는 첨가 중합으로 나온다.
- 교재의 «고분자 전해질 막을 사용한 고체 산화물 연료 전지» 서술은 부정확해 보여 출제하지 않았다.
