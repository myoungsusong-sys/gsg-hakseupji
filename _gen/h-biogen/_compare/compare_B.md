# h-biogen 갈래 B — 시중 문제집 1:1 비교 (유전자의 발현 · 생명공학기술)

- 시중 교재: 동아출판 하이탑 생물의 유전(22개정) 교사용 — Ⅱ 유전자의 발현(p98~156), Ⅲ 생명공학기술(p160~217)
- 교재 구분 표기: 기본=개념 기본 문제, 적용=개념 적용 문제, 도전=도전 문제, 통합=대단원 통합 실전 문제, 최상위=최상위 문제, 확장=확장 문제(서술형), 논구술=논구술 대비 문제
- 문항 수는 해당 단원 문제 면을 훑어 발문·자료로 유형을 배정해 센 대략값이다(한 문항이 두 유형에 걸치면 주된 쪽에 셈).
- 우리 기존 문항: 유형마다 6문항(난이도 1·2·3·3·4·5), 글·마크다운 표뿐이고 그림 0, 교재 표기와 다른 용어(리보솜, 억제 단백질, 작동 부위 등)가 섞여 있다.
- 보강: 유형마다 6문항(난이도 2·3·4·4·5·5), 교재 표기(라이보솜, 유전부호, 억제단백질, 작동부위, 젖당오페론, 호미오유전자, 단클론항체, 제한효소, 중합효소연쇄반응 등)로 통일. 그림 57장, 표 76개, 서술형 6문항.
