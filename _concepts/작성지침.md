# 개념카드 작성 지침 (「유형 마스터」 0층 빈칸의 재료)

학습지앱에서 학생이 **유형 문제를 틀리면 이 개념카드로 내려온다.** 카드의 문장에서
낱말과 수식을 자동으로 가려 **빈칸 문제**를 만든다. 그래서 **형식이 곧 기능**이다.

## 만드는 것

과정 하나에 파일 하나: `_concepts/<과정id>.json`

```json
[
  {
    "id": "c-e3-1-u0m0s0",
    "subId": "e3-1-u0m0s0",
    "title": "받아올림이 없는 세 자리 수의 덧셈",
    "lines": [
      "받아올림: 어떤 자리의 합이 $10$이거나 그보다 크면 윗자리로 $1$을 올려 주는 것.",
      "세로셈: 같은 자리끼리 줄을 맞추어 쓰고 일의 자리부터 차례로 더한다.",
      "자리별 계산: 각 자리의 합을 그대로 쓰면 되므로 $234+512 = 746$처럼 자리마다 따로 더한다.",
      "덧셈의 교환법칙: 두 수를 바꾸어 더해도 합은 같다 — $\\square + \\triangle = \\triangle + \\square$."
    ]
  }
]
```

- `subId` 는 입력 tsv 의 **첫 칸을 그대로** 쓴다. `id` 는 `c-` + subId.
- `title` 은 입력 tsv 의 마지막 `>` 뒤 **소단원 이름**을 그대로 쓴다.
- `lines` 는 **4~7줄.** 그 소단원의 유형(tsv 셋째 칸)을 푸는 데 실제로 쓰이는 것만.

## 반드시 지킬 두 가지 — 이게 없으면 빈칸이 안 나온다

### ① 「용어: 설명」 줄이 **최소 1줄**
줄머리에 정의할 낱말을 쓰고 콜론. 낱말은 **한글 2~11자, 숫자 없이.**

- ✅ `소인수: 어떤 자연수의 인수 중에서 소수인 것.`
- ❌ `최대·최소(2): …`  (숫자가 들어간 소제목은 용어가 아니다)
- ❌ `성질: …` `방법: …` `공식: …`  (일반 낱말은 답이 될 수 없다)

### ② `$...$` 안에 **괄호 밖 등호**가 있는 줄이 **최소 1줄**
우변을 통째로 가려 「$A = \square$」로 낸다. 그래서 **우변이 값어치가 있어야** 한다.

- ✅ `$S = 2\pi r h$` · `$2\times2\times2 = 2^{3}$` · `$(\text{넓이}) = (\text{가로})\times(\text{세로})$`
- ❌ `$y = f(x)$` (우변에 숫자·지수·연산이 없다) · `$\mathrm{P}(X=a) = 0$` (우변이 한 글자)
- ❌ `$f(x) \ge 0$` (등호가 없다)
- ⚠️ 등호가 **괄호 안에만** 있으면 안 잡힌다 — `$\mathrm{P}(X = x_i) = p_i$` 는 바깥 등호가 있어 ✅

초등은 한글을 `\text{}` 로 넣어 쓰면 된다: `$(\text{직사각형의 넓이}) = (\text{가로}) \times (\text{세로})$`

## 그 밖의 규칙

- **`예:` `참고:` `주의:` 로 줄을 시작하지 마라.** 그 줄은 빈칸에서 통째로 제외된다.
  예시는 문장 안에 `(예: 12의 소인수는 2와 3)` 처럼 괄호로 넣는다.
- 수식은 **KaTeX**. JSON 이므로 역슬래시는 `\\` 로 두 번 쓴다(`"$2^{3}$"`, `"$\\times$"`).
- `$` 는 반드시 짝을 맞춘다.
- 학년 눈높이를 지킨다. 초1~2는 수식보다 말로, 고등은 정확한 기호로.
- **틀린 개념을 쓰지 마라.** 애매하면 그 줄을 빼고 확실한 것만 쓴다.

## 다 쓰면 반드시 검사한다

```bash
cd ~/hakseupji-deploy && node _concepts/검사.mjs _concepts/<과정id>.json
```

`✓ 전부 통과` 가 뜰 때까지 고친다. 실패 줄은 어느 소단원이 무엇이 없는지 알려 준다.

## 먼저 데인 함정 (읽고 시작해라)

- **우변이 한 글자면 공식으로 안 세어진다.** `$3+2+1 = 6$` 은 탈락.
  좌우를 뒤집어 `$(\text{쌓기나무의 수}) = 3 + 2 + 1$` 로 쓰면 통과한다.
- **용어(줄머리 낱말)에 공백을 넣지 마라.** `받아올림` ○ / `받아 올림` ✗ (정규식이 공백을 안 받는다)
- 초등은 계산을 **손으로 검산**해라. 카드에 틀린 계산이 들어가면 그게 그대로 학생 화면에 뜬다.
